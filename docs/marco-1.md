# Marco 1

## Objetivo

Entregar a primeira fundacao funcional do EasyPrint, pronta para evolucao incremental.

## Entregas desta etapa

- monorepo configurado
- contratos compartilhados do documento
- validacao estrutural do documento via schema compartilhado
- base da API NestJS
- schema Prisma inicial
- modulos principais de template, impressora, job e auditoria
- autenticacao JWT bootstrap com tenant inicial
- app web com listagem e shell do editor
- store central do editor
- primeiros elementos do canvas
- preview inicial desacoplado

## O que ainda e propositalmente simples

- autenticacao e tenancy estao preparadas, mas ainda com implementacao inicial
- upload de imagem esta modelado e com ponto de extensao de API
- impressao teste ainda esta em modo preparatorio
- auditoria ainda cobre eventos centrais, nao toda a superficie do sistema
